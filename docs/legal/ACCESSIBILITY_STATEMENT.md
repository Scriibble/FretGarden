# FretGarden Accessibility Statement

Effective date: July 15, 2026

FretGarden aims to make focused guitar practice usable by learners with different access needs. Accessibility is part of the release-readiness process, not a decorative afterthought.

## Current Status

Automated accessibility and responsive checks are passing for the current curriculum and pilot surfaces. The project also has a Gate 4 human-review protocol for screen-reader, zoom, focus, assistive-input, and representative usability evidence.

Gate 4 human evidence is not fully closed yet. The project owner has confirmed that the screen reader works in the current pilot, but the complete protocol evidence still needs to be executed and recorded before final public release acceptance.

## Current Support

The current app includes:

- semantic page structure and labeled controls;
- keyboard-operable practice and pilot flows;
- reduced-motion handling for pulse animation;
- text equivalents for structured music blocks;
- persistent feedback and local-storage error messages;
- responsive layouts tested down to narrow mobile widths;
- explicit support/fade states in curriculum lessons.

## Known Limits

The full human protocol still needs:

- screen-reader matrix execution and signoff;
- visible-focus and zoom review;
- assistive-input review;
- touch-device review;
- moderated learner and educator sessions;
- resolution or explicit acceptance of any findings.

Some guitar learning tasks may involve sound, movement, visual fretboard diagrams, or self-assessed physical comfort. FretGarden should keep offering text equivalents and alternate input paths where possible, but the product is still under review.

## Feedback

Please report accessibility barriers during testing. Helpful reports include:

- the page or task where the issue occurred;
- browser, device, operating system, and assistive technology used;
- what you expected to happen;
- what actually happened;
- whether the issue blocked completion or made the task confusing.

# Codex Handoff Checklist

Before the first Codex prompt:

- [ ] The starter kit is copied into the repository.
- [ ] All 17 constitution PDFs are present.
- [ ] The root `AGENTS.md` references the education addendum.
- [ ] The repository is committed or backed up.
- [ ] Existing tests have been run and recorded.
- [ ] Codex has repository access.
- [ ] Codex is instructed to audit before implementing.
- [ ] Production schema changes require approval.
- [ ] Bulk curriculum migration requires approval.
- [ ] A pilot vertical slice is the first implementation target.

Before approving implementation:

- [ ] Current system inventory is complete.
- [ ] Compliance findings cite paths and chapters.
- [ ] Target architecture separates observations, evidence, claims, and decisions.
- [ ] Legacy progress treatment is defined.
- [ ] Rollback is defined.
- [ ] Pilot acceptance tests are defined.
- [ ] Unresolved decisions are visible rather than guessed.

Before approving full migration:

- [ ] Pilot passes constitutional and technical tests.
- [ ] Content authoring is practical.
- [ ] Review and remediation work end-to-end.
- [ ] Accessibility review is complete.
- [ ] Migration has been rehearsed.
- [ ] Educational debt is bounded and documented.

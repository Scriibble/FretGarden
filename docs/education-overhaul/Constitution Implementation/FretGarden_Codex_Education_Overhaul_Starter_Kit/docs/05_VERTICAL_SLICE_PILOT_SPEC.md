# Pilot Vertical Slice Specification

## Recommended pilot

Implement the opening learning sequence:

1. Garden philosophy and expectations;
2. focused-practice/Pomodoro introduction;
3. metronome fundamentals;
4. first fretboard orientation and note-retrieval objective.

This pilot touches practice mindset, session architecture, temporal control, fretboard learning, feedback, evidence, review, and progression without requiring the entire advanced theory curriculum.

## Required objective examples

### Practice regulation

The learner can select and follow a sustainable focused-work interval, identify the session's single primary target, stop or reduce load when attention or physical quality deteriorates, and describe the next useful practice action.

### Pulse synchronization

The learner can produce a simple repeated action aligned to an external pulse under defined tempo and subdivision conditions with specified stability and decreasing support.

### Fretboard note retrieval

The learner can produce designated natural-note locations within a constrained fretboard region from varied prompts without visible answer cues, then retrieve the same relationship after delay and in a changed context.

## Required pilot capabilities

- objective registry;
- prerequisite and readiness check;
- lesson-phase rendering;
- scaffold level;
- attempt and condition capture;
- dimensional feedback;
- reattempt;
- unsupported retrieval;
- task variation;
- exit evidence;
- delayed-review registration;
- readiness/progression decision;
- remediation route;
- learner-facing explanation;
- accessibility-equivalent response where practical.

## Required pilot scenarios

1. independent success;
2. success after a hint;
3. repeated retrieval error;
4. timing instability;
5. task or device failure;
6. learner chooses a shorter sustainable session;
7. delayed review succeeds;
8. delayed review reveals lapse;
9. prerequisite evidence is missing;
10. prior knowledge permits bypass with valid evidence.

## Pilot exclusions

Do not use the pilot to implement:

- the complete curriculum;
- every domain rubric;
- advanced adaptive algorithms;
- high-confidence audio diagnosis not supported by current technology;
- irreversible conversion of all learner progress.

## Acceptance criteria

The pilot passes only when:

- no mastery depends on completion alone;
- support is recorded;
- learner status distinguishes independent, prompted, and corrected performance;
- review occurs after delay;
- remediation changes the instructional response;
- the learner receives a specific next action;
- data can explain why progression occurred;
- all critical paths have automated tests.

## Upload Specs

Use a 1:1 square profile image and keep the mark centered for circular crops. Export PNG at 1080 x 1080 for a high-quality master, then use platform-specific compression only if needed.

Useful current references checked July 9, 2026:

- X recommends 400 x 400 profile photos and 1500 x 500 headers: https://help.x.com/en/managing-your-account/how-to-customize-your-profile
- TikTok profile photos must be at least 20 x 20 pixels: https://support.tiktok.com/en/getting-started/setting-up-your-profile/adding-a-profile-photo-or-video
- YouTube profile images render at 98 x 98 and support JPG, GIF, BMP, or PNG under 15 MB: https://support.google.com/youtube/answer/10456525
- Hootsuite's July 2026 guide is a useful cross-platform reference for profile and social image sizes: https://blog.hootsuite.com/social-media-image-sizes-guide/

## Setup Checklist

- Upload selected profile picture to every profile.
- Use the same display name and handle wherever possible.
- Add the same website/demo URL everywhere.
- Pin one "what this is" post before posting recurring tips.
- Keep profile pictures text-free; use banners and pinned posts for copy.
- Revisit the bio once the first public demo URL and domain are final.
